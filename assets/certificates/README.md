# Certificate assets

- `participation-template.png` — blank designer template (3508×2481) used by PDF generation
- `sample-certificate.png` — visual reference for text placement, colors, and paragraph copy
- `participation-preview.pdf` — local preview from `node scripts/previewCertificatePdf.js`

Fonts (Anek Devanagari) live in `backend/assets/fonts/`.

Do not put templates in `uploads/` or the frontend. Generation runs on the backend.
